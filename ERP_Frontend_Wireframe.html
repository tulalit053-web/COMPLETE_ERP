4. Struktur Sidebar (Dinamis)

  • Data diambil dari endpoint GET /me/menus
  • Hanya menu dengan showInSidemenu = 1 yang ditampilkan
  • Mendukung menu bertingkat (parent → child)
  • Icon diambil dari field iconName (jika ada)
  • Item aktif menggunakan warna Primary (#1E40AF)

5. Elemen Security di UI

  • Peringatan session timeout sebelum token habis
  • Halaman 403 jika user tidak punya permission
  • Indikator kekuatan password saat ganti password
  • Tombol logout yang jelas di header
  • Device ID dikirim saat memanggil POST /users/record-login
